# TASK-20260717-007 — Build a geometric identity and counterexample engine

## Objective

Create a structure-aware compiler that turns checked Clifford-algebra statements into exact host and CUDA evaluators, then searches deterministic finite-field assignments for counterexamples.

## Implemented in v1

- JSON identity IR and JSON Schema;
- dimensions one through six;
- diagonal non-degenerate signatures with entries `+1` or `-1`;
- exact arithmetic modulo an odd prime;
- grade-constrained variables;
- canonical expression DAG;
- common-subexpression elimination;
- exact blade-support propagation;
- scalar, additive, geometric-product, wedge, reverse, grade-projection, and commutator nodes;
- deterministic counter-based assignment generation;
- exact Python evaluator;
- generated host/CUDA evaluator;
- host smoke executable;
- CUDA counterexample search using one assignment per thread;
- minimal assignment index preservation with `atomicMin`;
- host reproduction of GPU witnesses;
- known-identity and deliberately false mutation corpus;
- deterministic tests, workflow, result validator, and evidence packaging.

## Initial corpus

True identities:

- vector square has only grade zero;
- reversion reverses product order;
- vector wedge product is antisymmetric.

Deliberately false mutations:

- vector geometric product is commutative;
- reversion preserves product order.

The false statements are acceptance tests. A successful engine must return an exact witness.

## Physical validation

The v1 engine was built and executed on an NVIDIA GeForce RTX 5070 Laptop GPU with CUDA 13.1.

- five statements;
- 1,048,576 exact modular assignments per statement;
- 5,242,880 total assignments;
- 4,096 CPU prechecks per statement;
- all three known identities survived the configured assignment set;
- both false mutations produced exact assignment-zero witnesses;
- GPU witnesses were reproduced by the host evaluator;
- aggregate CUDA assignment rate: 688,163,373.765 assignments per second;
- validator result: `VALIDATION: PASS`;
- manifest and archived evidence package created.

Exact witnesses:

- vector product commutativity mutation: assignment 0, blade 3, `-6 != 6`;
- reverse-order mutation: assignment 0, blade 2, `-9 != 9`.

## Interpretation boundary

Failure to find a finite-field counterexample is not a proof over characteristic zero. A witness is exact for the specified finite-field statement and is sufficient to reject that statement in that field.

The current corpus validates the compiler and search mechanism. It does not claim discovery of a previously unknown theorem.
