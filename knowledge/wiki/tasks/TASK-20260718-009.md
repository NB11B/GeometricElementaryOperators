# TASK-20260718-009 — Add grammar-bounded exact identity discovery

## Objective

Move from testing and mutating supplied identities to generating bounded families of geometric expressions, classifying them by exact blade-wise integer polynomials, and selecting exact relations for independent host/CUDA validation.

## Implemented

- checked JSON grammar configuration;
- deterministic expression enumeration by AST cost;
- canonical syntax keys and commutative-addition normalization;
- exact blade-wise integer polynomial classification for every expression;
- exact polynomial equivalence classes;
- primitive polynomial classes modulo integer content and overall sign;
- integer-multiple relation recovery;
- deterministic scoring and bounded relation selection;
- exact structural certificates;
- automatic near-miss controls with nonzero polynomial differences;
- deterministic finite-field prechecks for controls;
- v1-compatible prime-matrix corpus emission;
- manifest compilation into the existing host/CUDA evaluator;
- host/CUDA result validation and witness reduction;
- reproducible evidence manifests and archives;
- deterministic unit tests and a host workflow;
- a Windows CUDA evidence runner with environment normalization.

## Initial grammar corpora

1. Vector products in `Cl(4,0)`.
2. General multivector reversion/product relations in signature `(2,2)`.
3. Nested commutator and Jacobi relations in `Cl(3,0)`.

Representative baseline relations include:

- `[a,b] = 2(a ∧ b)` for vectors;
- `reverse(a b) = reverse(b) reverse(a)`;
- `[a,b] = -[b,a]`;
- the cyclic commutator Jacobi expression equals zero.

These are controls for the discovery mechanism rather than claims of new results.

## Interpretation boundary

The current result validates the grammar-bounded discovery machinery. A zero polynomial is exact only for its declared dimension, signature, variable grade supports, and commutative scalar-coefficient model. A finite-field witness is exact in its field. The selected corpus does not by itself establish novelty of any relation.
