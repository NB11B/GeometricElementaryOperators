# TASK-20260717-008 — Add multi-prime discovery and witness reduction

## Objective

Extend the validated v1 exact-search engine into a discovery layer with deterministic candidate mutation, multi-prime execution, exact polynomial classification, and reduced witnesses.

## Implemented

- deterministic prime-matrix corpus expansion;
- one-edit mutation generation with stable provenance;
- exact blade-wise integer polynomial extraction;
- primitive polynomial normalization and stable hashes;
- zero-polynomial classification;
- exact CPU screening before CUDA execution;
- manifest-driven host/CUDA evaluator generation;
- host reproduction of GPU witnesses;
- greedy witness reduction;
- cross-prime JSON and Markdown reports;
- resilient evidence finalization;
- deterministic compiler, discovery, result-validator, and witness-reduction tests.

## Interpretation boundary

The current corpus validates the discovery and classification machinery. A zero polynomial is exact for the declared dimension, signature, and grade supports, but it does not automatically quantify over other structural settings. A finite-field witness is exact in that field.

## Next stages

1. Cluster variants by primitive polynomial hash.
2. Add dimension and signature sweeps.
3. Add integer witness search seeded from reduced modular witnesses.
4. Export certificates and witnesses to proof-assistant formats.
5. Move from one-edit mutation to grammar-bounded candidate generation.
6. Apply the engine to Jacobi, rotor, duality, representation, Lie-algebra, topology, and operator-family corpora.
