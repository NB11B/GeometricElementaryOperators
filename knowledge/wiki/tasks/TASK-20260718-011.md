# TASK-20260718-011 — Add rewrite-distance classification and mixed-operator corpus

## Objective

Add derivation-aware classification, then build a new grammar corpus using operators and grade supports that are less dominated by immediate reversion, grade-support, and additive-normalization consequences.

## Classification levels

- known-direct
- known-derived-1
- known-derived-2
- support-derived
- tautological
- unclassified

Each derived classification must emit a deterministic derivation trace naming the source identities and rewrite steps.

## Initial rewrite rules

- reversion anti-automorphism
- reversion involution
- grade involution multiplicativity
- Clifford conjugation anti-automorphism
- commutator antisymmetry
- Jacobi identity
- grade-projection idempotence and orthogonality
- declared pure-grade support
- vector reversion invariance
- scalar-part symmetry where valid in scope
- additive, scale, and sign normalization

## New operators

- left contraction
- right contraction
- duality and unduality
- grade involution
- Clifford conjugation
- existing product, wedge, commutator, reverse, and grade projection

## Scope sweeps

Dimensions: 3, 4, 5, and 6.

Signatures: Euclidean, Lorentzian, and balanced signatures when available.

Variable supports: unrestricted, even, odd, vector, bivector, and mixed vector-plus-bivector.

## Acceptance gate

- classify the V3.1 vector-product reversion family as known-derived-1
- emit a derivation using reversion anti-automorphism and vector reversion invariance
- reduce the current 23 certificates to zero unclassified families
- keep rewrite search deterministic and bounded
- replay derivation traces successfully
- generate deterministic mixed-operator corpora
- preserve V3 exact polynomial and control compatibility
- require physical CUDA validation before promoting any new candidate
