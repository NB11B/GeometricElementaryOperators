# TASK-20260718-010 — Normalize and rank exact relation families

## Objective

Convert the physically validated V3 exact relation certificates into a deduplicated mathematical catalogue that suppresses syntactic restatements, identifies checked families, and preserves unclassified relations for novelty review.

## Implemented

- deterministic first-occurrence variable renaming;
- side-swap and simultaneous-sign quotienting;
- double-negation and nested-scale simplification;
- subtraction-by-zero normalization;
- double-reversion simplification;
- redundant grade-projection simplification;
- declared pure-grade projection and reversion reduction;
- additive canonicalization;
- scope-preserving family hashes;
- checked-family classification;
- tautology and support-derived tagging;
- novelty-oriented scoring;
- JSON and Markdown audit reports;
- unit tests for normalization and grouping.

## Acceptance gate

- equivalent sign and side presentations share one family key;
- variable-renamed copies share one family key;
- structurally different dimensions, signatures, or grade supports remain distinct;
- known V3 controls classify correctly;
- grade-support and projection tautologies receive penalties;
- unrecognized exact relations are retained as candidates;
- repeated audits are byte-for-byte deterministic;
- all existing V1-V3 tests remain passing.

## Current boundary

The V3.1 audit implementation and tests are checked in. Local execution against the finalized 23-certificate V3 evidence package remains the active acceptance gate.
