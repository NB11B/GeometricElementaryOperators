# TASK-20260717-003 — Fuse and lower the ESP32-C6 GEO IMU schedules

## Original request

Prepare the next benchmark after preliminary ESP32-C6 results showed that the generic GEO float path reproduced conventional task accuracy but paid substantial generic operator-composition overhead.

## Objective

Preserve the generic `A0` and `B0` evidence while adding sparse fused `A1` and `B1` schedules derived from the same paired-`Cl(2,0)` quaternion expression. Measure the effect of lowering and fusion without changing the replay, filter gains, reference, timer, output schema, or deadline.

## Preliminary evidence

The physical ESP32-C6 capture reported:

- A0 generic GEO float: approximately 185.526 microseconds per sample, 28-byte state, and task error equal to C at displayed precision.
- B0 generic GEO Q16: approximately 228.568 microseconds per sample, 32-byte state, bounded task error, zero NaNs, and zero deadline misses in the visible runs.
- C conventional quaternion: approximately 52.181 microseconds per sample.
- D quantized TinyML fixture: approximately 220.371 microseconds per sample.

The evidence indicates a lowering/fusion bottleneck rather than a mathematical-correctness bottleneck.

## Design

A0/B0 retain four complete generic `Cl(2,0)` products per quaternion product. A1/B1 lower the known sparse paired representation directly:

```text
q -> A + iB
A = w + y e12
B = x e1 + z e2
(A+iB)(C+iD) = (AC-BD) + i(AD+BC)
```

The A1/B1 schedules eliminate products involving known-zero grades, temporary multivectors, encode/decode structures, and repeated fixed-constant conversion.

A1 is expected to approach C because both represent the same fully lowered scalar schedule. This does not mean the conventional implementation became GEO; it demonstrates that the GEO expression can compile to the same minimal execution graph.

B1 uses:

- Q16 state and correction arithmetic;
- prequantized `dt`, `half_dt`, `kp`, and `ki`;
- fused Q32 accumulators rounded once to Q16;
- checked Q16 additions and state updates;
- fast float-to-Q16 boundary conversion;
- decoded float quaternion normalization followed by Q16 requantization.

## Acceptance criteria

- `GEO_AB_FUSION_CHECKS,status=pass` appears before results.
- Six implementations each emit 30 result rows.
- Complete output contains 180 data rows plus one header row.
- Every implementation has one stable named-field hash.
- A1 and B1 report zero NaNs and zero deadline misses.
- A1 accuracy remains equal to C within floating operation-order effects.
- B1 maintains bounded task error and zero arithmetic failures.
- A1 mean latency is materially lower than A0.
- B1 mean latency is materially lower than B0.
- The summary tool reports validation PASS.

## Implementation

- Added `geo_filter_fused.c` and `geo_filter_fused.h`.
- Extended the startup self-test to A0/B0/A1/B1/C.
- Registered six implementations in one benchmark run.
- Added `scripts/summarize_results.py` for strict result accounting and speedup reporting.
- Updated the benchmark README and preserved preliminary A0/B0 evidence.
- Opened draft PR #15 with the generic benchmark branch as its base.

## Validation performed

- The sparse float schedule was checked algebraically against the paired-`Cl(2,0)` product and conventional quaternion update.
- A numerical development mirror of the complete 12,000-sample replay predicted B1 mean error near 7.71 degrees with no Q16 overflow events. This is development evidence only.
- The 512-step startup threshold was checked against the expected Q16 error envelope.
