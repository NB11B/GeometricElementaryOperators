# v0.18.2 release gate

The v0.18.2 hotfix is intentionally isolated from the v0.19 backend work.

A merge candidate must satisfy all of the following:

1. GCC and Clang release builds pass in float and double precision.
2. ASan and UBSan pass, including one selected-path benchmark execution.
3. `geo_struct_program_execute` and `geo_banked_execute` are defined archive symbols.
4. The mandatory Windows/MSVC consumer links and validates the legacy `geo_optimized_witness_t` layout.
5. Embedded logarithm calls reject NaN and both infinities without modifying output storage.
6. Fixed-point RTL detects rounded-product overflow and final wide-sum overflow, while accepting cancellation cases allowed by the C backend.
7. The generated controller serializes dependencies, aborts on completed-operation overflow, keeps overflow sticky until reset/start, pulses `done` on both outcomes, and pulses `result_valid` only on success.
8. Benchmark stdout and generated JSON/Markdown state the exact operation/path matrix.
9. Every `vvp | tee` and `yosys | tee` pipeline runs with shell pipe failure propagation.
10. The CMake project version is `0.18.2`.

## Evidence identity

Run every command from a clean checkout of the candidate and record:

```sh
git rev-parse HEAD
git status --short
```

The release evidence is valid only when the reported commit matches the PR head and the status output is empty. A GitHub job that fails before checkout and exposes no steps or log is an infrastructure startup failure: it is neither a code failure nor a pass.

## Linux or Unix-like host gate

The following commands reproduce the Linux portions of the hosted matrix. They require CMake, GCC, Clang, Python 3, `nm`, Icarus Verilog, and Yosys.

```sh
set -euo pipefail

rm -rf local-gate
mkdir -p local-gate/logs

for compiler in gcc clang; do
  for precision in double float; do
    if [ "$precision" = double ]; then use_double=ON; else use_double=OFF; fi
    build="local-gate/${compiler}-${precision}"

    CC="$compiler" cmake -S . -B "$build" \
      -DCMAKE_BUILD_TYPE=Release \
      -DGEO_BUILD_TESTS=ON \
      -DGEO_BUILD_BENCHMARKS=ON \
      -DGEO_USE_DOUBLE="$use_double" \
      2>&1 | tee "local-gate/logs/configure-${compiler}-${precision}.log"

    cmake --build "$build" --parallel \
      2>&1 | tee "local-gate/logs/build-${compiler}-${precision}.log"

    ctest --test-dir "$build" --output-on-failure \
      2>&1 | tee "local-gate/logs/test-${compiler}-${precision}.log"

    nm -g --defined-only "$build/libgeo_kernel.a" \
      2>&1 | tee "local-gate/logs/symbols-${compiler}-${precision}.log"
    grep -Eq '[[:space:]]T[[:space:]]+geo_struct_program_execute$' \
      "local-gate/logs/symbols-${compiler}-${precision}.log"
    grep -Eq '[[:space:]]T[[:space:]]+geo_banked_execute$' \
      "local-gate/logs/symbols-${compiler}-${precision}.log"
  done
done

cmake --build local-gate/gcc-float --target benchmark_report \
  2>&1 | tee local-gate/logs/benchmark-report.log
```

### Sanitizers

```sh
set -euo pipefail

for precision in double float; do
  if [ "$precision" = double ]; then use_double=ON; else use_double=OFF; fi
  build="local-gate/sanitize-${precision}"

  CC=clang cmake -S . -B "$build" \
    -DCMAKE_BUILD_TYPE=Debug \
    -DGEO_BUILD_TESTS=ON \
    -DGEO_BUILD_BENCHMARKS=ON \
    -DGEO_ENABLE_SANITIZERS=ON \
    -DGEO_USE_DOUBLE="$use_double" \
    2>&1 | tee "local-gate/logs/sanitize-configure-${precision}.log"

  cmake --build "$build" --parallel \
    2>&1 | tee "local-gate/logs/sanitize-build-${precision}.log"

  ASAN_OPTIONS=detect_leaks=1:halt_on_error=1 \
  UBSAN_OPTIONS=halt_on_error=1:print_stacktrace=1 \
    ctest --test-dir "$build" --output-on-failure \
      -E '^selected_path_benchmark$' \
      2>&1 | tee "local-gate/logs/sanitize-tests-${precision}.log"

  ASAN_OPTIONS=detect_leaks=1:halt_on_error=1 \
  UBSAN_OPTIONS=halt_on_error=1:print_stacktrace=1 \
    ctest --test-dir "$build" --output-on-failure \
      -R '^selected_path_benchmark$' \
      2>&1 | tee "local-gate/logs/sanitize-benchmark-${precision}.log"
done
```

### Q-format matrix

```sh
set -euo pipefail

for fraction_bits in 1 8 16 24 30; do
  executable="local-gate/test-qformat-${fraction_bits}"
  clang -std=c11 -Wall -Wextra -Wpedantic -Wconversion \
    -fsanitize=address,undefined -fno-omit-frame-pointer \
    -DGEO_FIXED_FRACTION_BITS="$fraction_bits" \
    -Iinclude tests/test_qformat.c src/fixed.c src/fixed_geb36.c \
    -lm -o "$executable" \
    2>&1 | tee "local-gate/logs/qformat-build-${fraction_bits}.log"

  ASAN_OPTIONS=halt_on_error=1 \
  UBSAN_OPTIONS=halt_on_error=1:print_stacktrace=1 \
    "$executable" \
    2>&1 | tee "local-gate/logs/qformat-test-${fraction_bits}.log"
done
```

## Windows/MSVC ABI consumer

Run this from a Developer PowerShell for Visual Studio:

```powershell
$ErrorActionPreference = 'Stop'

Remove-Item -Recurse -Force local-gate-msvc -ErrorAction SilentlyContinue
cmake -S . -B local-gate-msvc `
  -DGEO_BUILD_TESTS=ON `
  -DGEO_BUILD_BENCHMARKS=OFF `
  -DGEO_USE_DOUBLE=ON
cmake --build local-gate-msvc --config Release `
  --target test_abi_consumer --parallel
ctest --test-dir local-gate-msvc -C Release `
  -R '^abi_consumer$' --output-on-failure

dumpbin /symbols local-gate-msvc\Release\geo_kernel.lib |
  Tee-Object -FilePath local-gate-msvc\symbols.log
Select-String -Path local-gate-msvc\symbols.log `
  -Pattern 'geo_struct_program_execute$' -Quiet |
  ForEach-Object { if (-not $_) { throw 'missing geo_struct_program_execute' } }
Select-String -Path local-gate-msvc\symbols.log `
  -Pattern 'geo_banked_execute$' -Quiet |
  ForEach-Object { if (-not $_) { throw 'missing geo_banked_execute' } }
```
