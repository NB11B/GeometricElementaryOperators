# v0.18.1 post-merge blocker resolution

A local review of merge `2ae375672dd7fbdd4432bdcd0fa043896ea3bc5a` found five gaps that were not exercised by the original green matrix. They are resolved in the v0.19 candidate rather than being hidden by the backend expansion.

## Resolved blockers

- **Benchmark undefined behavior:** the selected-backend fixed-point sink now uses defined unsigned mixing, and the executable runs in sanitizer validation.
- **RTL overflow mismatch:** generated fixed-point products and executable schedules expose overflow, invalidate data outputs on overflow, and use the same round-half-away-from-zero and checked intermediate contract as fixed C.
- **Missing ABI symbols:** the archive again exports `geo_struct_program_execute` and `geo_banked_execute`; CI verifies the symbols with `nm`, while normal tests link through the public names.
- **Non-finite EML input:** embedded exponential/logarithm routines reject NaN and non-finite domain/overflow inputs with explicit status.
- **Overstated benchmark labels:** the executable and result rows identify only the paths actually measured.

## Expanded regression gate

The final candidate adds:

- GCC and Clang float/double builds;
- ASan/UBSan tests plus execution of benchmark and numerical harnesses;
- Q1, Q8, Q16, Q24, and Q30 checks for fixed arithmetic, fixed Omega, and fixed routing control;
- ESP32 component compilation;
- CUDA Toolkit 13.x compilation for float and double, including generated CUDA schedules;
- fixed C/RTL nominal and overflow vector equivalence;
- RTL simulation and synthesis for product, controller, and executable schedules;
- reproducible workload and numerical-error artifacts.

A tag is still prohibited until this gate passes on the exact candidate commit. Compile-only CUDA and ESP32 validation are not represented as physical-device results.
