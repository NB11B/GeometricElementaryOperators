# v0.18.2 release blockers

The v0.18.2 hotfix must close the following gaps before performance or backend expansion is merged:

- make benchmark sinks free of signed-overflow undefined behavior;
- expose and test RTL fixed-point overflow instead of truncating silently;
- restore the public structured and banked executor ABI symbols;
- reject non-finite EML logarithm inputs consistently;
- rename benchmark output so it describes only the paths actually exercised;
- add release, sanitizer, ABI, and RTL regression coverage for each item.

Feature work for CUDA 13.0, unified benchmarks, complete fixed execution, ESP32-S3 validation, and C/fixed/RTL equivalence continues after this hotfix is merged.
