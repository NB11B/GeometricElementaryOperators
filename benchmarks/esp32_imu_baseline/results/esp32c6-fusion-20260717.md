A1 and C produced the same displayed accuracy and the same named-field output hash, `28d82ac5`, across every run.

## Supported conclusion

Sparse lowering and fusion removed approximately 71% of the generic GEO execution cost and brought the floating geometric schedule to measurement-level parity with the hand-specialized conventional quaternion implementation. The result indicates that the original overhead was predominantly caused by generic operator composition, known-zero work, temporary representation conversion, and missing fusion rather than by the geometric representation itself.

## Limitations

- Per-sample timing used the ESP-IDF microsecond timer. Sub-percent A1/C ordering requires cycle-counter measurement and randomized implementation order.
- B1 uses Q16 algebra and integration with decoded floating-point quaternion normalization.
- D uses deterministic fixture weights and is not a trained task-quality neural baseline.
- The clean main-based branch must be rebuilt and re-run before this result is attributed to the clean branch head.
